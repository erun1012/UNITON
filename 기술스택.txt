알츠하이머 보호자를 위한 알츠하이머 지원 서비스 앱
1. 관리자/이용자 모드
2. 복약 알림
-복약 알림 전송 -> 관리자가 지정 가능. 
3. 위치 인식 + 생활 패턴 이탈 감지
-초기 1-2주 정도를 학습 기간으로 잡아서 패턴을 AI로 저장. / 이탈 지속 시간 또는 거리 조건이 필요
4. 문자 알림(병원 일정)
-일정 관리 시스템을 제외하고, 관리자가 병원 예약이나 약 처방 날짜를 입력하면, 자동 문자 발송 기능
5. 예방 부문
-이미지/음성/반응속도 테스트 -> 인지 속도 변화 추적.
-차별화 : 단순 퀴즈 앱과 달리 개인화, 의료 데이터와 연결
-가족 영상 재생 : 단순 영상/사진 반복보단 퀴즈와 결합하여, 영상 속 목소리 기반 청각 자극 훈련
-관리자 측에서 주기적 퀴즈 정보 업데이트 가능하게
6. AI기반 이용자 패턴 레포트
-퀴즈 성적(정답/오답/반응속도) + 위치 이탈 빈도 + 복약 알림 횟수-> 총합 점수화
-주 또는 월 단위로 레포트 제작함. + 의료기관이 참고할 수 있는 자료 형태로 제작 -> 사업화/보험 연계 가능성 높아짐. 

이런 기획으로 앱을 만들어서 사업화하는 것을 최종 목표로 삼고 있어, 그치만 그러려면 우리의 아이디어가 너무 보편적이고 고유한 기술이 아닌 시중에 이미 존재하는 기술들이야. 그래서 인지능력 강화라던지 약 복약 알림 등의 기능을 제거하고 대표로 내세울 주제가 필요해. 

그래서 우리는 시장대상을 알츠하이머의 보호자들로 제한했고, 이제 우리만의 고유한 기술은 어떤걸 내세울 것인지 등을 정해야해. 그래서 위치추적 서비스를 통해서 알츠하이머 환자의 위치를 항상 확인하고 위험 지역으로 갈 때 막을 수 있는 그런 앱을 만들까 새롭게 고민해봤어.

기존에 삼성에서 보유한 기술인 SmartTings Family Care 는 IoT와 연계한 좋은 기술이지만 외부활동에 있어서 활동의 제약이 존재하고, 삼성 갤럭시 유저들만 사용할 수 있다는 점이 걸려서 이렇게 고안해 봤어. 혹시 좋은 아이디어나 방법이 있을까?

알츠하이머 환자 보호자의 편의를 위해, 알츠하이머 환자를 관리하는 앱을 만들고 싶어. 이 앱은 구독이든 협력이든 수익을 낼 수 있는 비즈니스 모델을 보유하고 있어야해.

또한 처음 앱 배포를 가정했을 때 무료버전을 배포하고, 이 후에 유료버전을 통해 앱 고객들을 유치하면서 이익을 내야하는데, 무료에서 유료버전으로 넘어갈 때 기술의 향상이 필요해. 새로운 기능이 추가되어도 좋고, 기존의 기능을 무료버전과 다른 혜택으로 발전시켜도 돼. 

그래서 결과적으로 우리 앱은 새롭게 위치추적을 통해 알츠하이머 환자를 통제함으로써 알츠하이머 보호자의 편의를 보장한다는 거야. 우리 앱에 더 필요한 기능들, 발전시켜야 할 기능들을 기존에 존재하는 서비스들과 차별성이 존재하는 기능으로 이야기해줘볼래? 최대한 길고 많이 얘기해줘.




1.실시간 위치 추적 + 위험 구역 예측 / 위험 구역 + 안심 존 설정
-GPS 추적 + AI 학습으로 생활 반경 패턴 학습.
-위험 구역 설정 가능. 위험 구역 접근 시 보호자 알림 기능
-안심 존 설정 가능. 안심 존 벗어나면 보호자 알림 기능
-유료 : 위험 지대 설정 개수 무제한, 위험 구역 AI 자동 추천
-유료 : 안심 존 설정 개수 무제한, 안심 존 벗어난 시간이 길어지면 보호자 알림 기능.

2.지연/정지 요청 기능
-보호자가 앱에서 ‘귀가 요청’ 가능, 이용자에게 전송.
-실시간 위치 공유와 연계

3.보호자와 이용자 간 상호작용 기능
-무료 : 위치 추적 기능 텀 부여
-유료 : 실시간 위치 추적 기능

4.공공 안전망 연계
-119, 경찰, 인근 병원에 보호자 동의 하, 긴급 신고 API 연계
-유료 : 보호자 부재 시 자동 대체 신고 서비스

5.리포트 작성
-위치 이탈 빈도, 평균 외출 시간 등 포함
-PDF 자동 생성
-유료 : 병원/보험사와 연계, 제출 가능.
